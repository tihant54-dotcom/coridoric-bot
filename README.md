# 🤖 Парсер коридоров — Telegram Bot
## Fonbet.by + Maxline.by | Реальные котировки

---

## Быстрый старт

### 1. Получи токен бота
Telegram → @BotFather → /newbot → скопируй токен

### 2. Вставь токен в config.py
```
BOT_TOKEN = "1234567890:AAH..."
```

### 3. Запуск

**Windows:** двойной клик на `ЗАПУСК.bat`

**Mac / Linux:**
```bash
pip install -r requirements.txt
python bot.py
```

---

## Команды бота

| Команда | Действие |
|---|---|
| /start | Главное меню |
| /football | Скан футбол |
| /basketball | Скан баскетбол |
| /hockey | Скан хоккей |
| /tennis | Скан теннис |
| /volleyball | Скан волейбол |
| /scan | Повторить последний скан |
| /auto | Вкл/выкл авто-уведомления |
| /help | Справка |

---

## Авто-уведомления

Включаются через меню или /auto.
Бот присылает найденные коридоры по расписанию (5/10/30 мин).

---

## Деплой на сервер (бесплатно)

1. GitHub: создай репо, загрузи код
2. Render.com → New → Background Worker
   - Build: `pip install -r requirements.txt`
   - Start: `python bot.py`
   - Env var: `BOT_TOKEN = твой токен`

---

## Как работает коридор

Fonbet тотал = 220.5 → ставишь **Больше 220.5**
Maxline тотал = 223.0 → ставишь **Меньше 223.0**
Ширина = 223.0 - 220.5 = **2.5**

Если итог матча между 220.5 и 223.0 → оба купона выигрывают ✅
